Self-improving agents teach themselves skills.

Try the demo View code

Agents that learn can learn the wrong thing.

Personal AI agents now turn completed tasks into reusable skills. One poisoned file can teach an agent a skill that leaks your data, and that skill runs again every time.

Threat 1

Skill poisoning

Injected instructions steer the agent into saving a malicious helper as a trusted skill.

Threat 2

Silent persistence

Once registered, the bad skill runs on every future task, long after the poisoned input is gone.

Threat 3

Model-judged safety

Asking the model "is this safe?" fails when the model itself has been manipulated.

Vet every skill before it exists.

Sandboxes stop bad actions at runtime. SovereignOS stops bad skills from being registered at all.

Static scan

Parses the skill without running it and infers what it really needs: network, shell, secrets, dynamic code.

02

Manifest diff

Compares those permissions with what the task justifies. A CSV task needs no network and no secrets.

03

Nemotron review

NVIDIA Nemotron on Nebius Token Factory explains the risk in plain language. It advises; it never decides.
